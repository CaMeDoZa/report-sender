# Report Sender

Простой PowerShell-скрипт для автоматизации ежедневной рассылки файлов отчетов по регионам через SMTP.

> **Note**: Проект содержит завязку на внутренние пути Windows (`d:\Otchety\...`) и хардкод конфигураций. Опубликован «как есть» в качестве архива/примера рабочей скриптовой автоматизации.

## Описание работы

- **Мониторинг файлов**: Ожидает появление Excel-отчетов в целевых папках (с настраиваемым таймаутом).
- **Отправка по SMTP**: Формирует и отправляет письма с вложениями адресатам по регионам (с поддержкой `CC`).
- **Ошибки и логирование**: Ведет лог выполнения, поддерживает повторные попытки (retry) при сбоях сети или SMTP.

## Структура

- `powershell/report-sender.ps1` — основной PowerShell-скрипт.
- `bash/` — нереализованные заготовки под Bash.
